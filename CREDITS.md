# Credits

## Fonts
Used for the track surface's road markings and decals (v38). Each font sits
in `full_throttle_flux/fonts/<name>/` with its licence file, `OFL.txt`. All
four are licensed under the **SIL Open Font License, Version 1.1**, which
allows bundling them with the game. They're used as-is (only rendered into
the decal atlas, never modified or renamed).
